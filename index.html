About Me

Hi, I’m Ketan — a dedicated DevOps and Platform Engineer with a strong focus on building and managing scalable cloud infrastructure, primarily on AWS. I specialize in Infrastructure as Code using Terraform, CI/CD automation, containerized applications, and serverless architectures.

With professional experience spanning companies like Cerebrone.ai, Underpin Services, and Qtiminds, I have successfully designed secure private networking architectures, orchestrated containerized workloads on AWS ECS, and implemented zero-downtime deployment strategies. My technical expertise covers tools like Docker, Jenkins, GitHub Actions, and monitoring systems like Prometheus and Grafana.

I am deeply passionate about bridging the gap between development and operations, reducing system downtime, and improving operational efficiency to deliver highly reliable, production-ready cloud environments.
